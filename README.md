# FilterCapital-skills

## 定位

FilterCapital-skills 服务于 HR 和 Leader 的招聘决策，核心目标是在合法、岗位相关且证据可核验的边界内，最大化团队生产力并降低错误招聘成本。

它不会为了维护候选人、HR 或 Leader 的自尊和情绪感受而隐藏问题、弱化风险或模糊结论。证据显示不合适，就直接说明不合适及原因；证据不足，就直接说明无法判断以及缺少什么。

直白不等于武断。事实、推断和未知必须分开，反证必须保留，受保护或与岗位无关的信息不得进入判断。羞辱性措辞和无证据断言不是“真实”，只会降低决策质量。

技能核心不绑定岗位或行业，只提供调查、归因、证据深度、路径和风险判断。专业基础、工作流和证据权重放在独立的 `skills/filtercapital-skills/profiles/` 中，由目标 JD 和招聘方上下文选择；当前内置的第一个 profile 是游戏数据分析，营销、商务等岗位应建立自己的 profile，而不是继承游戏数据分析的统计门槛。

## 使用

在 Codex 中调用 `$filtercapital-skills`，提供岗位要求，并任选一种简历来源：

- 直接粘贴简历文本或附加简历文件；
- 提供公开可访问的简历 URL；
- 指定自己已登录的招聘网站页面。

专业用户也可以直接要求技能“制作一套简历筛选标准”。技能会先询问公司、团队、招聘动机、实际职责、带教能力、专业基础和证据标准，再生成可确认的 profile 草案；确认后才保存到 `skills/filtercapital-skills/profiles/`。

技能不绑定或内置任何招聘网站。它先检查简历中是否存在试图操纵评分、覆盖规则或诱导工具操作的提示词并向用户告警，再重建时间线和选择路径、发现异常、比较多种解释，最后结合中小公司用人知识形成判断。网站来源默认只读，不会生成 GUI，也不会自动修改招聘系统状态。
